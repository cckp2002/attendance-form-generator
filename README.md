# 출결 확인서 자동작성 시스템

월별 출결 현황 엑셀을 올리면 결석 신고서·조퇴/지각/결과 확인서를 자동으로 작성해 PDF로 내려받는 웹 프로그램입니다.
설치가 필요 없고(Chrome·Edge), 비용이 들지 않으며, **모든 자료는 내 컴퓨터의 브라우저 안에서만 처리됩니다.**

## 선생님용 사용 안내

1. **엑셀 올리기** – 월별 출결 현황 `.xlsx`를 끌어다 놓습니다(여러 달 동시 가능). 파일명에 "1학년 1반"이 있으면 학년·반을 자동 인식하고, 없으면 직접 입력합니다.
2. **출결 분석** – 같은 학생·같은 출결구분·같은 사유로 **연속된 등교일**이면 확인서 1장으로 자동 통합됩니다. (질병결석과 출석인정결석, 조퇴와 결석은 사유가 같아도 따로 만듭니다.)
3. **통합 결과 검토** – 노란색(검토 필요)·붉은색(필수 확인) 행을 확인하세요. 학생 이름을 누르면 원본 기록이 보입니다. `수정`으로 사유·날짜·교시·종류를 고치고, `분리`/`선택 항목 수동 통합`으로 통합을 조정합니다.
4. **출력** – 작성일을 확인하고 PDF(한 장/통합), ZIP(개별·학생별 폴더), 인쇄 중 선택합니다.

주의할 점
- **휴업일**: 공휴일·재량휴업일·방학은 상단 `휴업일 설정`에 추가하세요. 추가하면 통합 결과가 다시 계산됩니다. (기본 공휴일은 2025~2026년분)
- **지각**: 등교 교시는 "마지막 결시교시 다음 교시"로 추정해 `검토 필요`로 표시합니다. 다르면 수정에서 직접 입력하세요.
- **조퇴**: 결시교시 중 가장 이른 교시를 시작 교시로 씁니다.
- 날짜가 많아 칸에 안 들어가면 **별지 페이지**가 자동으로 붙습니다.
- 서명란(보호자·담임)은 비워 둡니다. 제목 옆 괄호에는 세부 종류(질병/출석인정/미인정)가, 본문에는 출결구분 전체(예: 출석인정결석)가 들어갑니다.
- 브라우저를 닫거나 새로 고치면 작업 내용이 사라집니다(개인정보 보호). `작업 초기화`로 직접 지울 수도 있습니다.

## 개인정보
- 엑셀·PDF를 외부로 전송하지 않으며, 분석·PDF 생성 모두 브라우저에서 처리합니다.
- 브라우저에 저장하는 것은 설정(학교명, 휴업일)뿐이며 학생 정보는 저장하지 않습니다.
- 로그인·분석 도구·광고 스크립트가 없습니다.
- `.gitignore`가 `private-test/`와 `*.xlsx`를 제외합니다. **실제 학생 엑셀은 저장소에 올리지 마세요.**

## 개발자용
```powershell
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm test         # 통합 규칙·PDF 생성 테스트
npm run build    # dist/ 생성
```
테스트 중 실제 엑셀 검증은 `private-test/1학년 1반 월별 출결 현황.xlsx`가 있을 때만 실행됩니다(없으면 건너뜀).
시각 확인용 PNG: `$env:PDF_OUT="out"; npx vitest run tests/pdf.test.ts`

### 현재 배포 (gh-pages 브랜치 수동 배포)
`npm run build` 후 `dist/` 내용을 `gh-pages` 브랜치로 올립니다 (`dist/.nojekyll` 포함). 코드 수정 후 다시 빌드해서 같은 방식으로 올리면 갱신됩니다.

### GitHub Pages 자동 배포 (선택)
아래 방식은 `.github/workflows/deploy.yml`(저장소에는 아직 없음)이 필요하며, 올리려면 GitHub 로그인에 `workflow` 권한이 필요합니다.
1. GitHub에 새 저장소를 만들고 이 폴더를 push 합니다 (`main` 브랜치).
2. 저장소 **Settings → Pages → Source**를 `GitHub Actions`로 설정합니다.
3. push 하면 `.github/workflows/deploy.yml`이 테스트·빌드 후 자동 배포합니다. 상대 경로(`base: './'`)라 저장소 이름과 무관하게 동작합니다.

### 구조
`src/lib/excel.ts`(병합 셀 포함 엑셀 읽기) · `merge.ts`(통합 규칙) · `calendar.ts`(등교일) · `pdf/clean.ts`(원본 PDF의 `{{…}}`·`2025년` 글자를 콘텐츠 스트림에서 실제 제거) · `pdf/spec.ts`(양식 배치 데이터) · `pdf/generate.ts`(작성) · `pdf/subset.ts`(HarfBuzz 글꼴 서브셋).
라이선스: pdf-lib·fontkit·PDF.js·ExcelJS·JSZip·HarfBuzz(MIT/Apache), 글꼴 나눔고딕(OFL).

## 구현된 기능 / 제한 사항
구현: 병합 셀 처리, 자동 분류·통합, 휴업일·등교 토요일 설정, 수동 수정·통합·분리, 필터·검색, 미리보기(실제 PDF와 동일), 통합 PDF·ZIP·학생별 ZIP·인쇄, 별지, 학교명 변경.
제한:
- PDF 양식 교체는 **기본 양식과 같은 글자 배치**일 때만 가능합니다. 클릭·드래그로 입력 위치를 지정하는 편집기는 후속 단계입니다.
- 기본 공휴일은 2025~2026년만 포함합니다.
- 지각 확인서 서명란의 학생 이름은 원본에 자리가 없었으나 다른 양식과 맞춰 채웁니다.
- 원본 글꼴이 아닌 나눔고딕으로 다시 쓰므로 글자 모양이 약간 다릅니다. 변경하지 않은 안내문은 원본 그대로입니다.
